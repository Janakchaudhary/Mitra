# Milestone 15 — Dynamic Activities and Compact Learning UI

## Color game

- Rotates through balloon, apple, kite, fish, flower, and car drawings.
- Each round uses a deterministic changing target color.
- Child matches a visual color sample, then identifies the Gujarati name, English name, and spelling.
- Adds eight colors and varied multiple-choice distractors.

## English Sentence Builder

- Expands from 5 to 12 sentence puzzles.
- Covers `this`, `that`, `and`, `is`, `are`, `a`, and `an` in varied contexts.
- Adds rule-specific hints for incorrect word order.
- Child can tap a selected word to remove it.
- Uses clearer two-column word tiles and compact progress UI.

## Rough work

- Correct place-value order is now left-to-right: `દશક` then `એકમ`.
- Column calculation rows share the same operator/tens/ones alignment.
- Guided entry fields also display `દશક` before `એકમ`.
- Instruction still explains that calculation begins with the ones column.
- Notebook height is reduced and the whole rough-work card can collapse.

## Learning page

- More compact header, question card, feedback, voice input, and controls.
- Replay and hint are icon controls.
- Next question uses a floating arrow/check icon instead of a full-width button.
- Stop, skip, and answer actions share one compact action row.
