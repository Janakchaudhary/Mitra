# Milestone 13 — Purposeful Motion and Child-Friendly Visual Polish

Version: `0.13.0` (`versionCode 22`)

## Goal

Make Mitra feel responsive, warm, and playful during short learning sessions without adding addictive mechanics or increasing the configured screen-time limits.

## Added

- Animated Mitra mascot moods: idle, listening, thinking, encouraging, and celebrating.
- Slow decorative learning-shape background on child-facing screens.
- Press/bounce feedback for child home and activity cards.
- Animated session progress.
- Slide/fade transition between learning questions.
- One-shot success burst after correct effort.
- Animated hint and feedback cards.
- Pulsing listening microphone state.
- Animated loading/thinking state.
- Floating balloon and animated color fill in Color Lab.
- Animated Sentence Builder puzzle transitions and success response.
- Animated Study Talk message entry and listening/thinking states.
- Brighter but readable child-facing Material 3 palette and rounded shapes.

## Deliberate limits

This milestone does not add:

- infinite reward feeds
- streak pressure
- coins or loot boxes
- autoplay sessions
- flashing effects
- longer screen-time limits

Animations support comprehension and feedback. Existing session and daily limits remain unchanged.

## Upgrade

- Room database version remains `5`.
- No database migration is required.
- Stable GitHub signing configuration remains unchanged.
